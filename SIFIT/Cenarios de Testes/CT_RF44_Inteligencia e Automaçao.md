

## Cenário de teste: Inteligência e Automação. (RF44)

### Caso de Teste 01: Visualizar central de automações.

| ID | Descrição |
| --- | --- |
| **C44-CT01** | O sistema deve listar as automações. |

| **Pré-condições** |
| --- |
| O usuário deve estar logado no sistema. |

| **Passos** |
| --- |
| **DADO** que o usuário acessa "Inteligência & Automação" |
| **QUANDO** a tela carregar |
| **ENTÃO** devem aparecer "Automações ativas" e "Automações disponíveis" |

| **Critérios de aceitação** |
| --- |
| As automações devem ser listadas. |

| **Evidência** |
| --- |
|  |
